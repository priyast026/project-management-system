🚀 Project Management System

A full-stack Project Management System that helps teams efficiently manage workspaces, projects, tasks, and team collaboration. It includes secure authentication, task assignment, comments, email notifications, and a modern responsive interface.

 🌐 Live Demo

https://project-management-system-cyan-eight.vercel.app/

 📂 GitHub Repository

https://github.com/priyast026/project-management-system

---

 ✨ Features

- 🔐 Secure authentication with Clerk
- 👥 Workspace creation and management
- 📁 Project creation and organization
- ✅ Task creation, editing, and deletion
- 👤 Assign tasks to team members
- 💬 Comment system for tasks
- 📧 Email notifications for assigned tasks
- 📅 Due date management
- 📊 Task status tracking (To Do, In Progress, Done)
- ⚡ Priority management (Low, Medium, High)
- 🎯 Project progress tracking
- 📱 Responsive user interface
- ☁️ Cloud database integration
- 🚀 Deployed on Vercel

 🚀 Installation

 Clone the repository

```bash
git clone https://github.com/priyast026/project-management-system.git
```

 Install dependencies

Frontend

```bash
cd client
npm install
```

Backend

```bash
cd server
npm install
```

 Configure Environment Variables

Create `.env` files for both client and server.

Example:

```env
DATABASE_URL=
CLERK_SECRET_KEY=
CLERK_PUBLISHABLE_KEY=
CLERK_WEBHOOK_SECRET=
```

 Run the application

Backend

```bash
npm run server
```

Frontend

```bash
npm run dev
```
